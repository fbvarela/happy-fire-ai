# Happy Fire MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the current dashboard shell into a transparent, location-based forest-fire risk estimator with explainable local-context inputs.

**Architecture:** Keep domain logic independent from React and external providers. A server-side environment context feeds a pure scoring function; the client renders the score and validated manual local-context inputs. Start with browser geolocation and deterministic mock data, then add one validated provider at a time.

**Tech Stack:** React 19, TypeScript, TanStack Start, TanStack Router, Nitro Vercel preset, browser Geolocation API, Canvas 2D, Vitest.

**Spec:** `spec.md`

## Global Constraints

- Use React with TanStack Start and TanStack Router instead of Next.js.
- Deploy the web app on Vercel.
- Keep provider keys and data fetching on the server side.
- Use TypeScript throughout the application.
- The score is deterministic, versioned, explainable, and never generated by an LLM.
- Missing or stale data lowers confidence and is never silently treated as safe.
- No unofficial route or simulation is presented as evacuation guidance.
- Do not store precise locations by default.
- Do not add map, AI, or visualization dependencies until a native/browser implementation is insufficient.

## Scope

## Current Status

- MVP dashboard, deterministic scoring, provider-backed environment context, Copernicus land cover, WorldPop exposure, and optional Cohere explanations are implemented.
- The Canvas simulation was removed because it did not provide useful decision support.
- Escape-route recommendations are not implemented. No unofficial route must be labeled safest or presented as evacuation guidance.

### Included in MVP

- Select a location with browser geolocation or latitude/longitude inputs.
- Display a timestamped environmental context using deterministic mock data.
- Calculate a 0-100 risk score with factor breakdown and confidence.
- Collect optional manual local festival/event pressure and roadside ditch maintenance inputs.
- Show missing-data, stale-data, and provider-error states in the data model.
- Keep the safety notice visible and direct active emergencies to official local authorities.

### Explicitly Deferred

- Google Maps rendering and route planning.
- Cohere/Grok-generated explanations.
- Official alerts, evacuation routes, accounts, saved locations, and notifications.
- Historical model training and claims of fire prediction accuracy.
